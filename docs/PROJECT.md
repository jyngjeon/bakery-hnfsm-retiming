# 프로젝트 지침과 계획

출처는 두 가지다. 과제 목차는 수업 제안서 작성 지침이고, 팀 범위·실험·일정·역할은 [팀13 프로젝트 제안서](proposal/team13-proposal.pdf)다. 제안서에 없는 내용은 추가하지 않았다.

## 1. 과제 산출물 목차 (수업 지침)

1. **연구 배경 및 선정 논문**: 연구 배경과 논문 선정 이유, 선정 논문의 기본 정보와 주요 연구 내용
2. **스케줄링 문제 정의**: 대상 스케줄링 문제의 정의와 특성, 목적함수·의사결정·주요 제약조건
3. **기존 방법론**: 선정 논문이 제안한 방법론의 개요, 주요 아이디어와 알고리즘 구조
4. **구현 계획**: 기존 방법론의 구현 범위와 방법, 데이터와 벤치마크 인스턴스, 구현 환경과 사용 도구, 선정 논문의 결과 재현·검증 계획
5. **개선 및 확장 아이디어**: 기존 방법론의 한계와 개선 가능성, 제안하는 개선·확장 아이디어, 기존 방법론과의 차이점과 기대 효과, 개선·확장 방법의 구현 계획
6. **실험 및 프로젝트 수행 계획**: 실험 설계와 비교 방법, 성능평가 지표, 예상 결과와 기대 효과, 수행 일정과 역할 분담

## 2. 문제 정의 요약 (제안서 2장)

- **모델**: Hybrid No-wait Flow Shop Scheduling Model (HNFSM)
- **목적함수**: makespan 최소화(인건비·생산성과 직결)와 OIDT 최소화(오븐 공회전 에너지 낭비 방지)
- **의사결정 변수**: 작업 시작시각 `ST_{g,p,s}`, 기계 배정 `O_{g,p,s,k}`, 작업자 배정 `O_{g,p,s,l}`
- **주요 제약**
  - 그룹 첫 작업 시작시각 ≥ 0
  - 그룹 내 bowl time(WT) 시차 유지(M6), no-wait(M8–M9)
  - 작업당 기계 1대(M10), 단일 처리 설비는 한 번에 작업 1개(M11)
  - 오븐은 같은 제품 그룹의 작업만 동시에 수용(M12). 휴지·냉각 공간 등은 용량 무제한(M13)
  - 수작업은 작업당 작업자 최대 1명(M15). 작업자는 동시에 두 작업을 할 수 없고(M16), 근무시간 안에서만 작업한다(M17–M18)
  - 기계·작업자 중 하나만 배정하거나 아무 자원도 쓰지 않을 수 있다(M19)

## 3. 기존 방법론 요약 (제안서 3장)

- 다목적 알고리즘이 후보해(연속 벡터)를 만들고, SPV로 그룹 순서로 바꾼다. HNFSM이 시각과 자원을 배정하고 (makespan, OIDT)를 평가한 뒤, 이 과정을 반복한다.
- 스케줄링 단위는 제품 그룹이다. 그룹 안의 기준 제품과 파생 제품 사이 시차(WT)는 고정된다.
- 기준 알고리즘은 NSGA-II다. 논문에서 종합 평가가 가장 우수했기 때문이다.
- 논문 설정(Table 5): population 50, binary tournament, SBX crossover(rate 1), polynomial mutation(rate 1/제품 그룹 수).

## 4. 구현 범위와 계획 (제안서 4장)

**파이프라인**: 데이터 정리 → 알고리즘이 그룹 순서 생성 → decoder로 스케줄 생성 → makespan·OIDT 평가 → 논문 결과와 비교

**HNFSM decoder**
- 입력은 그룹 생산 순서다. 그룹마다 가능한 가장 이른 시작시각을 1분 단위로 찾는다.
- 반영하는 제약: no-wait, bowl time, 기계·오븐 용량, 작업자 근무시간
- 출력: 스케줄, makespan, OIDT

**알고리즘**
- 5종(NSGA-II, SPEA2, GDE3, OMOPSO, SMPSO), SPV 변환, 논문 Table 5 설정(population 50, iteration 50–300)
- 비교 기준선: random search, 데이터 원래 순서
- 논문에 없는 세부 규칙은 기본값을 정하고 문서화한다

**알고리즘 우선순위**
- 최소 구성은 1~3순위다.
- 4~5순위는 진행 상황에 따라 추가한다. SMPSO는 OMOPSO와 결과가 비슷해 가장 후순위다.

| 순위 | 알고리즘 |
|---|---|
| 1 | NSGA-II |
| 2 | SPEA2 |
| 3 | OMOPSO |
| 4 | GDE3 |
| 5 | SMPSO |

**재현 실험** (제안서 4.4)

| 실험 | 내용 | 규모 |
|---|---|---|

- **논문 비교 수치**
  - BK15: PF* 해 3개, E1→E2에서 makespan +9분, OIDT −21분
  - BK50: PF* 해 7개, E1→E2에서 makespan +61분, OIDT −1348분
- **평가지표와 판정**: PDS, MSF, DPF, RHA, GMM cluster를 쓴다. 판정은 수치 일치보다 경향 일치 정도로 한다(Pareto front 모양, makespan 최소 해 ≠ OIDT 최소 해, BK50 알고리즘 순위; Kruskal–Wallis, Wilcoxon, Holm 보정).
- **구현 검증**: 논문 Table 1 손계산 예제, 독립 checker(위반 0건), Gantt chart로 OIDT 대조, makespan 하한과 random search 대비 확인
- **추가 실험**: 구현 가정 민감도(batch, oven 선택, OIDT 계산 방식), 평가 횟수별 hypervolume 수렴, 계산 시간, BK15 최소 makespan의 CP-SAT exact 비교, BK20 적용

## 5. 개선 아이디어: Group-Based Event-Point Retiming (제안서 5장)

상세 명세는 [proposal/proposal-idea-01-event-point-retiming.md](proposal/proposal-idea-01-event-point-retiming.md)에 있다.

- **한계 인식**: HNFSM은 우선순서대로 빈자리에 가장 빨리 넣는 greedy 배치다. OIDT를 평가하지만 배치 단계에서 직접 줄이지는 않는다. 그래서 생성된 시각 배치가 국소최적이라는 보장이 없다.
- **방법**: 다른 그룹의 시각과 모든 자원 배정은 고정하고, WT와 no-wait를 보존한 채 한 그룹 전체를 Δ만큼 평행이동한다(`ST = T_g + a_{g,p,s}`).
- **절차**:
  1. 오븐 최초·최종 사용에 관여하는 경계 그룹을 고른다.
  2. 실행가능 시작시각 구간 `F_g`를 계산한다(자원 충돌, 근무시간, makespan 한도).
  3. event point를 평가한다. 후보는 구간 끝점과 OIDT 함수의 꺾임점이다.
  4. 가장 좋은 이동을 1회 적용한다.
  5. 비악화 여부와 독립 실행가능성을 확인한다.
- **수락 조건**: makespan과 OIDT 모두 비악화이고, 하나 이상 개선될 때만 수락한다. 충돌이 없으면 자원 처리순서가 바뀌는 것은 허용한다.
- **최적성 범위**: 한 그룹 국소 이동 부분문제에 한정된다. 전체 스케줄의 전역최적이 아니다.
- **OIDT 정의**: 오븐 구획별 점유구간의 합집합으로 계산한다. 팀의 자체 해석이며 논문 식 M2와 구별된다.
- **제안서에 적힌 BK15 예비 검증**: 기존 방식의 저장 스케줄 66개 중 54개에서 OIDT 개선이 가능했고, 5개 seed 평균 HV 변화는 +2.08%였다. 이 예비 검증의 코드와 데이터는 이 저장소에 없다(확인 필요).

## 6. 실험·평가 계획 (제안서 6장)

- **핵심 질문**: Retiming을 추가하면 makespan은 유지하면서 OIDT가 줄어드는가?
- **비교 구성**
  - B0: NSGA-II → SPV → HNFSM decoder → (makespan, OIDT)
  - P1: B0에 Retiming을 추가한 것

| 실험 | 목적 | 비교 대상 | 데이터 |
|---|---|---|---|
| A. 재현 | 논문 결과 재현 | 알고리즘 5종 | BK15, BK50 |
| B. 개선안 비교 | Retiming 효과 확인 | B0 vs P1 | BK15 → BK50 |

- **추가 검증**: Ablation(Retiming 구성요소별 기여, BK15), 부분문제 검증(Retiming 결과를 소형 예제 전수탐색과 비교)
- **동일 조건**: 같은 instance, HNFSM decoder, NSGA-II 설정(Table 5), seed, 초기 population
- **예산**: (1) 같은 평가 횟수 15,000회, (2) 같은 실행 시간. seed 10개로 seed별 짝지어 Wilcoxon 검정
- Retiming은 NSGA-II에만 적용한다. 나머지 4종은 실험 A의 비교군이다.

**지표**

| 구분 | 지표 | 실험 |
|---|---|---|
| 주 지표 | Hypervolume(HV), 최소 makespan, 같은 makespan 해들의 OIDT | A, B |
| 보조 지표 | Retiming으로 개선된 해 비율, OIDT 감소량, 실행 시간 | B |
| 재현용 논문 지표 | PDS, MSF, DPF, RHA | A |

- 모든 해는 독립 checker로 위반 0건을 확인한 뒤 비교한다.
- HV는 B0와 P1의 해를 합쳐 정규화한 뒤 같은 reference point로 계산한다.

**예상 결과와 한계**
- 예상: 논문 재현은 수치 근사와 경향 일치를 기대한다. Retiming은 같은 makespan에서 OIDT가 줄어들 것으로 예상한다. 근거로, 논문 BK15에서 makespan 최소 해들 사이 OIDT 차이가 최대 150분이었다.
- 한계: 같은 실행 시간 기준에서는 Retiming 비용 때문에 이득이 줄 수 있다. 최종 HV 우위는 보장되지 않는다.
